\# CloudKnowledge



CloudKnowledge is a cloud-native document knowledge platform built with .NET and Azure.



The project is designed to demonstrate production-oriented backend engineering practices including asynchronous processing, distributed systems, observability, security, Infrastructure as Code, and AI-powered Retrieval-Augmented Generation (RAG).



\## Project Status



🚧 Early development



The project is currently being built incrementally, starting from a modular monolith and introducing distributed components only where they provide a clear architectural benefit.



\## Planned Architecture



\- ASP.NET Core API

\- PostgreSQL

\- Redis

\- Azure Blob Storage

\- Azure Service Bus

\- .NET background worker

\- Angular frontend

\- Semantic Kernel

\- Embeddings and vector search

\- Retrieval-Augmented Generation (RAG)



\## Engineering Goals



\- Clean and maintainable architecture

\- Asynchronous document processing

\- Reliable messaging and idempotency

\- Containerized local development

\- Automated CI/CD

\- Infrastructure as Code

\- Production-grade observability

\- Secure authentication and secret management

\- Automated testing
